## 🌐 Page Overview

### 1. Basic HTML Tasks (`Bai01.html` – `Bai06.html`)
* **`Bai01.html`**: Heading hierarchy (`<h1>`–`<h5>`) and paragraph structure.
* **`Bai02.html`**: Academic layout using headings, line breaks `<br>`, and email links.
* **`Bai03.html`**: Demonstration of external URLs and relative internal links.
* **`Bai04.html`**: Internal fragment navigation (`#id`), images, and captions (`<figure>`, `<figcaption>`).
* **`Bai05.html`**: Semantic layout structuring (`<section>`, `<article>`) for media and text.
* **`Bai06.html`**: Topic article with text emphasis (`<em>`, `<strong>`) and image integration.

### 2. Personalized Portfolio (`Portfolio.html`)
A complete single-page personal portfolio featuring:
* **Navigation:** Smooth section scrolling via fragment links (`#about`, `#skills`, `#projects`, `#education`, `#contact`, `#source`).
* **About Me:** Profile summary with structured portrait image.
* **Skills:** Core programming & tool competencies.
* **Projects Table:** Structured HTML table (`<table>`, `<thead>`, `<tbody>`) displaying academic projects.
* **Contact Form:** Pure HTML static input form (`<form>`, `<label>`, `<input>`).
* **Embedded Source Code:** On-page HTML preview using `<pre>` and `<code>`.
* **Footer:** Direct contact integrations (`mailto:`, `tel:`) and external GitHub link.
